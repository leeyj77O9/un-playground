# 출력창 숨기기 토글 — 설계 (소규모)

## 의도
에디터 작업 영역이 좁을 때 출력창을 접어 코드만 전체 너비로 보고 싶다.
사용자가 선택한 방식은 에디터 툴바의 토글 버튼이다.

## 목표 / 비목표
- 목표: 툴바 오른쪽(타입 검사 옆) 버튼으로 출력창 표시/숨김을 전환한다. 숨기면 분할 손잡이와 출력창을 제거하고 에디터가 100% 너비가 된다. 같은 버튼으로 복원하며, 선택 상태는 localStorage에 저장해 새로고침 후에도 유지한다.
- 비목표: 출력창 크기 조절 방식 변경, 새 단축키, 실행 동작 변경.
- 안티골: 숨긴 상태에서 버튼이 사라져 복원할 수 없게 되는 것.

## 접근 방식
1. **툴바 토글 (선택)**: 복원 경로가 항상 보이고 코드 변경이 적다. 상태 저장을 통해 새로고침 후에도 사용자의 선택이 유지된다.
2. 출력창 내부 닫기 버튼 + 툴바 토글: 직관적이지만 버튼이 두 개가 되어 상태 동기화가 필요하다. 선택하지 않음.
3. 툴바 토글만 만들고 상태 미저장: 가장 단순하지만 매 새로고침마다 다시 눌러야 한다. 선택하지 않음.

## 구현 메모
- `Home`이 `outputVisible` 상태와 localStorage 키(`un-playground-output-v1`)를 소유한다.
- `SourceEditor`에 표시 상태와 토글 핸들러를 전달하고 `toolbar-tail`에 아이콘 버튼을 추가한다.
- 숨김 상태에서는 `resize-handle`과 `TerminalPanel`을 렌더링하지 않고 `--editor-width`를 `100%`로 설정한다.
- 아이콘은 기존 `ToolbarIcon`에 출력창/닫힌 출력창 벡터를 추가해 폰트·브라우저에 영향받지 않게 한다.
